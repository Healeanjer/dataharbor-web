# DataHarbor Web · 企业数据平台官网

独立新建的三语展示型官网工程，目录名为 `dataharbor-web`。页面上继续使用临时品牌「企业数据平台」，正式品牌可后续统一替换。

## 当前首页与备份

- 新版首页：`/`；英文 `/en/`；繁体 `/zh-hant/`。页面组件为 `src/server/Home.tsx`。
- 旧版备份：`/home-previous/`，三语均可访问，不列入导航。页面组件为 `src/server/HomePrevious.tsx`。
- 旧 `/home-preview/`（含英文与繁体）自动跳转至对应语言首页；本地预览服务返回 308，静态 HTML 提供脚本及 meta 跳转后备。保留查询参数和页面锚点。
- 顶部与手机菜单已移除预览入口，首页已移除预览徽标和对照链接。

## 范围与来源

- 本版重新实现页面、样式、导航、响应式布局、交互及动画。
- 从已有成果迁入的内容仅为业务文案数据、我们已整理的英文和繁体译文、16 张交接包概念截图；不搬运旧版页面组件、样式、动画组件或构建脚本。
- 数据位于 `src/content/business.json`；三语词条位于 `src/content/en.json`、`zh-hant.json`、`additions.json`。
- 图片保持原样，文件、原始尺寸及 SHA-256 记录在 `ASSET_MANIFEST.json`。
- 使用 Next.js、React、TypeScript 等通用基础依赖。`DEPENDENCIES.json` 记录依赖清单，`THIRD_PARTY_NOTICES.txt` 保留安装包提供的许可证/NOTICE。独立编写应用代码不等于第三方依赖无需遵守许可。

旧工程仍保存在同级 `datavault-web`，本版不引用该目录中的运行时代码、配置或资源。

## 启动与验证

需要 Node.js 20.9+，建议使用当前验证的 Node.js 24。

```sh
npm ci
npm run check
NEXT_TELEMETRY_DISABLED=1 npm run build
npm run verify
npm run preview
```

预览默认地址：`http://127.0.0.1:4174/`。可通过 `PORT=端口 npm run preview` 修改本地端口。预览服务只监听本机地址，不会公开发布。

开发模式：`npm run dev`。构建为纯静态 `out/`；各语言拥有自己的根布局，HTML 的语言和页面元数据在服务端生成，不依赖构建后的字符串替换。

## 目录与页面

- `src/app/(chinese)`：简体中文原始路径 `/`。
- `src/app/(english)/en`：英文 `/en/`。
- `src/app/(traditional)/zh-hant`：繁体 `/zh-hant/`。
- `src/server`：共享内容模板与页面分发。
- `src/components`：本版独立编写的组件和交互。
- `src/app/site.css`：本版设计令牌、组件样式和响应式规则。
- `src/i18n`：翻译函数、语言路径与上下文。

每种语言包含 29 个内容页和 1 个错误页：平台简介、技术体系、能力矩阵、15 个模块详情、解决方案及 5 个详情、交付与选型、价格方案、关于我们、隐私政策和用户协议。

## 交互实现

- 半透明灰色玻璃导航；按对应栏目定位、按内容选择宽度的下拉菜单。
- 手机导航整行展开，子菜单以网格行高与透明度平滑过渡；展开时锁定背景滚动，并避免背景进入键盘焦点。
- 语言菜单保留当前页面、查询参数和锚点；原截图不随语言转换。
- 截图随滚动产生透视变化；内容进入视口时渐进出现；数字增长与信息标签滚动。
- 可键盘切换的能力选项卡；原生 dialog 截图放大；横向轮播支持触屏滚动和按钮。
- 通过 Canvas 2D 自行绘制的数据球，使用球面点阵投影与旋转，不依赖地球绘制库。离屏/后台时暂停，支持拖动旋转。
- 问答平滑展开；页脚和悬浮按钮返回当前页面顶部，手机悬浮按钮仅保留圆形箭头。
- 尊重系统「减少动态效果」设置。

## 内容状态

现阶段为官网概念预览，未接入真实试用、支付或业务后台。「试用产品」进入能力矩阵；价格为「联系咨询」；公司、资质、联系方式、二维码、备案及法律条款继续明确占位。没有补造业务事实。

如提供正式二维码，可设置 `.env.example` 中对应变量后重新构建。正式域名确认后可设置 `NEXT_PUBLIC_SITE_URL`，用于生成规范 URL 和多语言关联地址。当前默认不允许搜索引擎索引。

## 检查

`npm run verify` 检查所有导出页面的语言、一级标题、英文中文残留、站内链接、锚点、图片存在性和截图哈希。结果保存在 `VERIFICATION.json`。桌面、手机和平板关键交互另通过浏览器检查，不以静态链接检查代替交互验收。

## 配色与滚动展示（2026-11-12）

采用深海蓝、冰蓝、青绿与通透玻璃的统一视觉。首页通过浅色首屏、滚动能力叙事、深蓝架构、场景卡片与浅色球体收尾形成浏览节奏。

- 桌面宽度达到 1000px 且未启用减少动态效果时：五段能力说明随正常页面滚动推进，右侧截图保持固定并切换；圆点也可定位到对应段落。不拦截滚轮或触摸。
- 手机、平板与减少动态效果模式：保留可点击与键盘切换的能力标签，避免长距离固定叙事。
- 增强了截图展开、内容错峰进入、架构连线光点、场景卡片反馈和首尾柔光。截图文件与业务内容保持原样，三语共用同一套效果。
- 无新增动画依赖；滚动使用 requestAnimationFrame，减少动态效果模式关闭位移与持续动画。

### 展示效果细化

- 工作台图采用平整的应用窗口框，仅做轻量进入，不再随滚动旋转和缩放；预览窗口裁取顶部内容，点击仍可查看完整原图。
- 能力叙事的五张截图保持挂载，以同位叠层、短距离横移和透明度衔接切换；左侧文字完整清晰显示。
- 概念界面改为居中大卡片轮播，两侧显示前后预览，支持循环箭头、圆点、方向键及横向拖动/滑动。无自动轮播，无横向滚动条。
- 页尾恢复浅蓝绿背景，球体配色适配浅底；架构章节仍保留深蓝色。

- 独立动效实验目录仍保留，整合无需新增依赖。
